# Prototype d'application de découverte d'événements

## Lancement de l'application
1. Lancer les Web Services (WS) :
   ```bash
   cd backend
   pip install .
   python3 run src/main.py
   ```
2. Lancer le serveur Web de développement :
   ```bash
   npm install
   npm start
   ```
3. Ouvrir [http://localhost:3000](http://localhost:3000) dans votre navigateur.
